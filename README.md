# Template Batch Filler

一个超轻量网页工具：把模板中的 `{{变量}}` 批量替换为 JSON 数据，快速生成多份文案。

## 为什么做它
近期在 Product Hunt/社区里持续出现“求模板自动化”“批量生成文案”的需求信号。这个工具可在 90 分钟内交付可用 MVP。

## 功能
- 模板占位符替换（`{{name}}`）
- JSON 数组批量生成
- 页面内预览
- 一键下载 `results.txt`
- 纯前端，本地运行，不依赖 API

## 本地运行
直接打开 `index.html` 即可。

## 部署
本项目为静态站点，适配 Vercel。
